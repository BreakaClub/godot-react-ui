Fonts for the text styles lab and its Chrome reference (docs/tracks/utilities-text.md). They are in the demo only: the library
works with the theme font alone. Each is licensed under the SIL Open Font License 1.1; the licence of each is beside it.

OpenSans-Variable.ttf, OpenSans-Italic-Variable.ttf   Open Sans, variable (wght 300 to 800, wdth 75 to 100)   OFL-OpenSans.txt
PTSerif-Regular.ttf, PTSerif-Bold.ttf                  PT Serif, static, unmodified                           OFL-PTSerif.txt
JetBrainsMono-Variable.ttf                             JetBrains Mono, variable (wght 100 to 800)             OFL-JetBrainsMono.txt

Source: https://github.com/google/fonts (ofl/opensans, ofl/ptserif, ofl/jetbrainsmono), unmodified.
